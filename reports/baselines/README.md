# Sentiment baselines (generated)

> Generated by `uv run python -m medsignal.baselines.report` from the JSON files in this folder.
> Commit `8cb7fdf-dirty`. Sanity baselines only (ADR-0010); the project's headline task is ADE extraction.

Task: 3-class sentiment from star rating (neg 1-4 / neu 5-6 / pos 7-10). Model selection on `val`; `test` = seen drugs, `drug_holdout` = unseen drugs (ADR-0013).
Encoder: mean ± sample std over seeds.

|---|---|---|---|---|
| Majority class | test | 0.245 | 0.580 | 0.000 |
| Majority class | drug_holdout | 0.246 | 0.586 | 0.000 |
| TF-IDF + logistic regression | test | 0.634 | 0.753 | 0.681 |
| TF-IDF + logistic regression | drug_holdout | 0.594 | 0.725 | 0.626 |
| BioClinical ModernBERT (fine-tuned) | test | 0.646 ± 0.002 | 0.832 ± 0.011 | 0.776 ± 0.021 |
| BioClinical ModernBERT (fine-tuned) | drug_holdout | 0.613 ± 0.002 | 0.811 ± 0.011 | 0.725 ± 0.025 |

**Reading this table.** The encoder is far better on negative and positive reviews, but its
neutral-class F1 on `test` is 0.219 vs 0.310 for TF-IDF, which limits its
macro-F1 gain. Two causes: TF-IDF+LR uses `class_weight=balanced` while the encoder uses
unweighted cross-entropy (neutral is 8.8% of training data), and 5-6-star reviews are often
mixed in tone, so the star rating is a noisy label for text sentiment.
On unseen drugs (`drug_holdout`) macro-F1 drops by 4.0 points (TF-IDF + logistic regression), 3.4 points (BioClinical ModernBERT (fine-tuned)).
